# What each source offers for the next features

The filter and file-list features planned for dataseek (server-side filters by license, update date, format and resource type; a resolve step that lists a dataset's files without downloading them; paging past the first page; total hit counts; links from a dataset to the papers and datasets related to it; machine-readable metadata for `inspect`) depend on what each provider exposes. One row per registry id, as probed or read from the provider's documentation on 2026-10-06. A cell is the exact parameter, field or endpoint, or `none`. This file records only; none of these is implemented, because each needs new `Dataset` fields and CLI flags.

Columns: **license**, **date** and **format** filters; **type** is a resource-type filter; **manifest** is a file list with names, sizes, checksums or download URLs; **paging** is the parameter and the deepest reachable result; **total** is a hit count; **related** is papers or datasets linked to a record; **machine** is Croissant, schema.org JSON-LD, DCAT or another structured record. Rows of one protocol module (CKAN, Dataverse, NADA, SDMX, STAC, Socrata, EBI) repeat the protocol's cells; a difference between portals is named in the cell.
